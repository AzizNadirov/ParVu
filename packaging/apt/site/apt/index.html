ParVu APT repository

Install ParVu on Ubuntu 22.04 or newer, Debian 12 or newer and their derivatives (64-bit), and get updates with sudo apt upgrade.

Install

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL @SITE_URL@/apt/parvu-archive-keyring.gpg | sudo tee /etc/apt/keyrings/parvu-archive-keyring.gpg >/dev/null
echo "Types: deb
URIs: @SITE_URL@/apt
Suites: stable
Components: main
Architectures: amd64
Signed-By: /etc/apt/keyrings/parvu-archive-keyring.gpg" | sudo tee /etc/apt/sources.list.d/parvu.sources >/dev/null
sudo apt update && sudo apt install parvu

Or let the installer script do the same:

curl -fsSL https://raw.githubusercontent.com/AzizNadirov/ParVu/main/install.sh | bash -s -- --apt

Pre-releases

Write Suites: beta instead of Suites: stable to also get alpha, beta and release-candidate versions. The beta suite always includes the newest stable release too.

Signing key

The repository is signed with this key (armoured, binary). Check its fingerprint:

gpg --show-keys /etc/apt/keyrings/parvu-archive-keyring.gpg

@FINGERPRINT@

Uninstall

sudo apt remove parvu
sudo rm /etc/apt/sources.list.d/parvu.sources /etc/apt/keyrings/parvu-archive-keyring.gpg

Settings, recent files and themes in ~/.ParVu are kept.
