# Translations (i18n)

ParVu is available in:

- 🇬🇧 **English** (`en`)
- 🇷🇺 **Russian** (`ru`) - Русский
- 🇦🇿 **Azerbaijani** (`az`) - Azərbaycan

Change the language in View → Language or File → Settings. The change applies immediately and is saved as `current_language` in `~/.ParVu/settings/settings.json`.

## Where translations live

Each language is one flat JSON file in `crates/parvu-config/locales/`:

```json
{
  "menu.file": "File",
  "status.loaded": "Loaded: {filename} ({rows:,} rows)"
}
```

Keys contain dots but are not nested. The files are compiled into the app, so a change needs a rebuild.

If a key is missing in the current language, English is used, then the key itself.

## Placeholders

Placeholders use Python `str.format` syntax, which the files were originally written in:

| Placeholder | Meaning | Example |
|---|---|---|
| `{name}` | value as is | `Customer 7` |
| `{rows:,}` | thousands separators | `1,234,567` |
| `{size:.1f}` | fixed decimals | `12.3` |
| `{{` `}}` | literal braces | `{` `}` |

Every language must use the same placeholder names as English for a key.

## Using translations in the UI

```tsx
const { t } = useUi();
t("menu.file");                                              // "File"
t("status.loaded", { filename: "sales.parquet", rows: 100000 }); // "Loaded: sales.parquet (100,000 rows)"
```

Rust code that needs a translated message uses `I18n::tr` from `parvu-config`.

## Adding a key

Add it to all three JSON files, keeping the files sorted by key. The test `locales_complete_and_placeholders_match` in `parvu-config` fails if a language is missing a key or uses different placeholders:

```bash
cargo test -p parvu-config
```

## Adding a language

1. Copy `locales/en.json` to `locales/<code>.json` and translate every value.
2. In `crates/parvu-config/src/i18n/mod.rs`, add the language to the `LANGUAGES` list (code, English name, native name, flag), add a `LazyLock` catalog with `include_str!`, and add it to `catalog_for`.
3. Run `cargo test -p parvu-config`. The completeness test checks every registered language automatically.
